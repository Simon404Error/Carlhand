## 二、仍未找到对应命令的功能（需走内存/属性锁）

- 移速/奔跑倍率 → 已用属性锁实现（`MaxWalkSpeed`、`JumpZVelocity`、`GravityScale`、`JumpMaxCount`，已验证）
- 霸体（免疫抓捕/控制/负面状态）→ 命令表无对应项，需找 `PlayerHealthComponent` / `StatusEffect` 上的免疫开关（真实属性已探明：`InvulnerabilityDuration`、`IronWillActive`、`HealthRegeneration`、`ShieldRegenDelay`、`DamageTakenMutator`、`SharedHealthMutator` 等）

## 三、特征状态文件协议（DLL 菜单 ↔ Lua 引擎）

`<游戏目录>\FSD\Binaries\Win64\FSDTrainer_features.txt`（UTF-8 无 BOM），一行一条 `键=值`：

```
walk_speed=450      移速（MaxWalkSpeed 锁）
jump_z=750          跳跃初速
gravity=0.6         重力倍率
jump_max=99         多段跳次数
godmode=1           无敌（bCanBeDamaged=false + C_GodMode）
jetboots=1          喷气靴子 MK2（C_JetBoots_Enable_MK2）
inf_flare=1         无限照明弹
unlock_all=1        一键解锁
killaura=1          杀戮光环（每 300ms C_KillAll）
```

Lua 引擎 `FSDTrainer_code.lua`（热加载，改完在 `FSDTrainer_cmd.txt` 里重写 `lua <8.3短路径>` 即生效，无需重启游戏）每 300ms 读此文件并应用，逐功能独立 pcall 保护，出错不会中断循环。

## 四、已知坑

1. `FSDTrainer_cmd.txt` 必须是 **UTF-8 无 BOM**，带 BOM 时第一条命令解析失败（表现为 `[命令] lua ...` 前缀乱码）。
2. 不要遍历 `GObjects` 全表做反射（会崩游戏）；只按名取 3 个对象以内。
3. 太空舱（SpaceRig）里调喷气靴子/部分命令有崩溃风险，功能验证请在落地任务中进行。

## 五、落地实现（2026-09-18 20:11 实测通过）

链路：**菜单(DLL) → FSDTrainer_features.txt → 游戏内 Lua 引擎 v10 → ExecuteConsoleCommand → 游戏**

- kind=cheat 机制：菜单开关直接写状态文件，不需要扫描/绑定地址；动作型每次点击把值 +1，引擎按“值变化”触发，可重复点；「全部关闭（恢复）」写 0 并恢复原状
- DLL 启动时自动部署 FSDTrainer_code.lua（引擎 v10）并在 FSDTrainer_cmd.txt 写 lua <8.3短路径>；游戏重启后自动重新加载
- 引擎 v10 表驱动：LOCKS（走速/跳跃初速/重力/跳跃次数连续锁）+ ACT（40+ 条命令），**以后加功能只改 ini 的 key，不用改 Lua**
- 实测：godmode=1→C_GodMode ok=true 且 CanBeDamaged=false；inf_flare=1→C_FlareInfiniteDuration ok=true；reak_armor=1→C_BreakAllEnemyArmor ok=true
- ini 现状：89 个功能节（24 个转为 cheat，13 个新增），旧版在 FSDTrainer.ini.bak
